# **App Name**: FluxiDocs

## Core Features:

- Dashboard View: Display a dashboard with key document metrics, such as total documents, types of documents, and recent activity.
- Document Upload: Enable users to upload documents of various types (PDF, images, XML, etc.).
- Document Categorization: Categorize documents based on 'tipo_documento' field in the database (e.g., invoices, reports, contracts).
- Document Search: Allow users to search documents by keywords, date ranges, or other metadata fields.
- Database Integration: Fetch document data and metadata from the provided MySQL database.
- AI Document Summarization: Generate document summaries using AI to quickly understand document content. This feature uses a tool to decide if a summary can be meaningfully created from the given input.
- Comprehensive document view: Show document data from all tables in the schema
- Financial Overview Dashboard: Display key financial data (Total Ingress, Total Expenses, Benefit before taxes) in a summarized view, inspired by the provided spreadsheet layout.
- Incidence Validation Section: Create a dedicated section for documents where 'incidencia' is true, requiring validation.

## Style Guidelines:

- Dark purple (#4A2878) for a professional and sophisticated feel.
- Very dark gray (#121212) to create a modern and focused environment.
- Bright purple (#9400D3) to highlight important elements and actions.
- 'Inter', a sans-serif font, is recommended for both headlines and body text because it offers a modern and neutral aesthetic suitable for both.
- Use flat, minimalist icons in a light color to ensure clarity against the dark background.
- Implement a clean and organized layout, focusing on usability and quick access to documents.
- Add subtle animations for transitions and interactions to enhance the user experience.
